# irl.ing

**Less scrolling. More irl’ing.**

Irl’ing is a verb: being present, seeing what’s around you, and doing something with it. irl.ing is a six-second social video app built around feeds that end. You hold to record, let go to pause, and your moment loops for your friends. There are no filters. Then you put the phone down. Recording, loops and the tech below work today in the loops lab; profiles, friends and feeds come next. It runs in the browser on any phone or desktop.

## What’s here

- **`/`**: the landing page, kept minimal. A live hold-to-record loop runs through the lab's finishing pipeline, followed by three one-line steps and **the lexicon**: plain names for the tech (Hold-to-Loop, Featherweight, Lifeboats, Lighten Up, Real Seal, True Grain, Glow-Up, Honest Zoom, Smart Pixels, Cosmic Courtesy). Two small demos show smart pixels and how a loop survives a bad link. It ends with "You're caught up."
- **`/loops/`**: the loops lab, for phone or desktop. Tested in Chromium (Chrome, Edge) so far; Safari, iPhone and Firefox are next. Hold-to-record works with touch, mouse, or Space and Enter.
  - **Encoding:** clips are encoded on the phone with its own AV1 encoder (VP9 or H.264 where AV1 isn't available) to a 50, 100 or 200 KB budget.
  - **Packaging:** each loop is cut into two-second, checksummed chunks and signed with a key that never leaves the phone.
  - **Playback:** loops are rebuilt lifelike with FSR 1 upscaling and sharpening, measured film grain and dithering, with an optional "smart pixels" look.
  - **Honest Zoom:** after upscaling, an integer lock makes every 2×2 block average exactly to the received pixel, so added detail can never contradict what was sent. Frames are checked on playback and before export. See [Honest Zoom](docs/honest-zoom.md).
  - **Saving and sharing:** **Save video** and **Share video** make a normal MP4 (H.264, 720²) that plays anywhere. The `.irl` file plays only on irl.ing and remains a secondary download.
  - **No camera needed:** **Try the sample** works without one.

  See [little loops v2](docs/loops-v2.md).
- **Brand**: the logo system (the take mark, the wordmark, app icons, share image), palette, type and voice are in [docs/brand.md](docs/brand.md). Logo files live in `public/brand/` and are generated by `node scripts/brand/build.mjs` (`--png` re-renders the PNGs with Playwright). The typeface, Schibsted Grotesk, is self-hosted from `public/fonts/`.

- **Accounts** (`/api/auth/*`, one Vercel function): claim an @name and save it with a passkey (fingerprint, face or screen lock), no password. Better Auth on Postgres (Neon). Friends-only by default; teens can’t be found by strangers. Off until `DATABASE_URL` and `BETTER_AUTH_SECRET` are set. See [accounts](docs/accounts.md).

- **Friends and sharing** (same function; switched on for previews, off on irl.ing until launch). Mutual friends by invite link or exact @name, plus blocks. Sharing a loop to friends works like this: the server checks its Real Seal, Claude reviews three still frames against the community rules, and it's stored privately on Cloudflare R2. A feed that ends, reports and a human review queue complete it. See [the backend](docs/social.md) and [user safety](docs/user-safety.md).

On irl.ing today, loops aren’t uploaded: they stay on the phone until someone shares the file.

## Run

Node.js 22.12+ or 24 is required.

```sh
npm ci
npm run dev        # http://localhost:3001
```

Production build:

```sh
npm run build
PORT=3003 npm start
```

Vercel deploys `master`; `vercel.json` selects Vite, `npm run build` and `dist/`. Commit the lockfile with any dependency changes.

## Test

```sh
npm test
# With the production server running on port 3003:
STUDIO_URL=http://127.0.0.1:3003 node tests/landing-browser.mjs
STUDIO_URL=http://127.0.0.1:3003 node tests/loops-browser.mjs
# Accounts need Postgres; see docs/accounts.md:
SITE_URL=http://localhost:3004 node tests/accounts-browser.mjs
```

Unit tests cover the loop container (damage, truncation, relay trimming, signatures and tampering), grain estimation and color conversion. The browser tests need Playwright and Chromium, which this cloud environment provides; set `CHROMIUM_PATH` to choose a browser. They use Chromium's fake camera and microphone at phone-sized viewports. Nothing has been verified on a physical Android phone yet.
