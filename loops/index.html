See what survives a bad link. Each test changes the file the way a relay or a noisy channel would, then plays what is left.

Videos save as an MP4 that plays anywhere: your gallery, messages, any app. It’s rendered at 720² with the same finishing you see here. : about 100 KB, in sealed two-second chunks, but it only plays on irl.ing.

The .irl file is AV1 video (VP9 or H.264 where AV1 isn’t available) in two-second chunks that each carry a checksum, signed by a key that never leaves this phone. Sharpening, upscaling, grain and smart pixels are added on playback and are labeled as such. The raw clip stays on this phone.
